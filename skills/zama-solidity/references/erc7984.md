# ERC-7984 Confidential Tokens

Build on OpenZeppelin's [confidential contracts](https://github.com/OpenZeppelin/openzeppelin-confidential-contracts) and read the installed package source for the exact API. Do not write your own encrypted balances, allowances or transfers.

- **Move real tokens.** A payment, escrow or vault must transfer tokens. Encrypted numbers recorded beside a token are not custody.
- **Operators replace allowances.** Before a contract can call `confidentialTransferFrom`, the holder calls `setOperator(contract, until)` on the token. Operator rights expire at `until`. They allow transfers only. Reading a balance needs a separate access grant.
- **Transfers can move zero.** A transfer the sender cannot pay, or a receiver callback that declines, moves an encrypted zero. Use the returned amount.
- **Use the token's units.** Amounts are `euint64`. OpenZeppelin's default is 6 decimals. Extensions can differ. A wrapper's `decimals()` and `rate()` can differ from its ERC-20's. Use integers only.
- **Name overloads explicitly from ethers.** Transfer functions have one overload for an external input with proof and one for an existing handle.

Find deployed wrappers in the registry (**zama-protocol** → `references/addresses.md`). For deployed payment and escrow designs, read `code-map.md`.
